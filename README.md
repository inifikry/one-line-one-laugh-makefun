# One Line, One Laugh

Entry for the make.fun competition
`u-coral-404-one-line-one-laugh-22f2c9f3` ("One Line, One Laugh").

## What it does

`main.py` writes a single funny line of at most 200 characters to
`/output/entry.txt`. The line is a constant in the source, so the program
is fully deterministic: every run produces the same output.

## The line

> I bought a standing desk to get healthier. It now holds my chair.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
